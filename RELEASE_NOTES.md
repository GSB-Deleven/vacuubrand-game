## 🇩🇪 Professor Vacuumus 0.9.0 (Vorabversion)

Das VACUUBRAND Messespiel zum Herunterladen. Läuft ohne Installation und ohne Internet.

> ⚠️ **Vorabversion:** Die Tests auf echten Geräten (Tablet, iPhone, Mac, Raspberry Pi, Arcade-Joystick) und die Freigabe der Texte durch das Marketing stehen noch aus.

**Installieren**
1. Unten bei „Assets“ die Datei **`Professor-Vacuumus-v….zip`** herunterladen.
2. ZIP entpacken (Windows: Rechtsklick → „Alle extrahieren“; Mac: Doppelklick). Es entsteht der Ordner `Professor-Vacuumus`.
3. Ordner z. B. auf den Desktop legen und die Start-Datei doppelklicken:
   - 🪟 Windows: `▶ START Windows.bat`
   - 🍎 Mac: `▶ START Mac.command` (beim ersten Mal: Rechtsklick → **Öffnen** → Öffnen)
   - 🍓 Raspberry Pi / Linux: `▶ START Linux + Raspberry Pi.sh` (automatischer Start: `raspberry-pi/README.md`)
   - Notfalls: `index.html` doppelklicken

Alles Weitere steht in `ANLEITUNG.md` im Ordner. Die Versionsnummer steht im Admin-Bereich (Strg + Shift + A).

## 🇬🇧 Professor Vacuumus 0.9.0 (pre-release)

The VACUUBRAND trade show game to download. Runs without installation and without internet.

> ⚠️ **Pre-release:** Tests on real devices (tablet, iPhone, Mac, Raspberry Pi, arcade joystick) and the marketing approval of the texts are still pending.

**Installation**
1. Under "Assets" below, download **`Professor-Vacuumus-v….zip`**.
2. Unzip it (Windows: right-click → "Extract All"; Mac: double-click). You get the folder `Professor-Vacuumus`.
3. Put the folder e.g. on the desktop and double-click the start file:
   - 🪟 Windows: `▶ START Windows.bat`
   - 🍎 Mac: `▶ START Mac.command` (first time: right-click → **Open** → Open)
   - 🍓 Raspberry Pi / Linux: `▶ START Linux + Raspberry Pi.sh` (automatic start: `raspberry-pi/README.md`)
   - If in doubt: double-click `index.html`

Everything else is in `GUIDE.en.md` in the folder. The version number is shown in the admin area (Ctrl + Shift + A).
