# Vorschlag für die Discussions

## Kategorien (Settings → Discussions → Kategorien bearbeiten)

| Kategorie | Format | Wofür |
|---|---|---|
| 📣 Ankündigungen | Announcement | Neue Versionen, Termine |
| 💡 Ideen | Open-ended discussion | Lose Ideen fürs Spiel (Vorlage `ideen.yml` wird automatisch verwendet, wenn die Kategorie den Slug `ideen` hat) |
| 🎪 Messe-Feedback | Open-ended discussion | Erfahrungen nach jeder Messe (Slug `messe-feedback`) |
| ❓ Fragen | Question / Answer | Fragen zu Bedienung und Technik |

Reife Ideen: in der Discussion rechts auf **„Create issue from discussion“** klicken. Im Issue dann **@claude** schreiben, wenn Claude sie umsetzen soll.
