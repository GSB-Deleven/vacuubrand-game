# 🔐 Admin-Bereich

**Öffnen:** Laptop: **Strg + Shift + A** auf Titel, Ergebnis oder Bestenliste. Tablet: 3 Sekunden aufs Logo drücken. Danach PIN (Standard `1234`, **unbedingt ändern**). In der Online-Demo gibt es keinen Admin-Bereich.

| Bereich | Funktion |
|---|---|
| Übersicht | Spieler und Runden heute / gesamt |
| Top 3 | heute (Tagespreis) und ganze Messe, mit Kontaktdaten |
| Export | Leads (CSV/Excel), alle Runden (CSV/Excel), Sicherung (JSON). Der Inhalt erscheint zusätzlich in einem Textfeld mit „Inhalt kopieren“ |
| Sicherung laden | ergänzt Daten aus einer JSON-Sicherung (nichts wird überschrieben) |
| Referenzdaten laden (Test) | Beispieldaten mit erfundenen Personen, zum Ausprobieren |
| Einstellungen | Messename, Rundenzeit (30 bis 600 s), PIN, Tagespreis und Hauptpreis (erscheinen auf Startbildschirm und Bestenliste), Gerätesprache (Vorwahl in der Länderwahl: Deutsch, Englisch, Französisch; das Titelbild ist immer Englisch), Admin-Sprache (Deutsch oder Englisch), Schalter **Nur Spitzname** (Anlass ohne Leads: nur Spitzname wie online, gelber Warnbalken im Admin, Spitznamen nicht im Leads-Export). Werden nur auf dem Gerät gespeichert |
| Letzte Runden | einzeln löschen (✕ zweimal) |
| Gefahrenzone | alle Daten löschen (LÖSCHEN eintippen) |
