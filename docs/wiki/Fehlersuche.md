# 🧯 Fehlersuche

| Problem | Lösung |
|---|---|
| Bestenliste plötzlich leer | anderer Browser, anderer Ordner oder Browserdaten gelöscht → Sicherung (JSON) im Admin laden |
| Windows fragt nach „Einrastfunktion“ | 5× Shift gedrückt. In Windows unter Barrierefreiheit → Tastatur abschalten |
| Kein Ton | einmal eine Taste drücken oder tippen, **M** prüfen, Lautstärke |
| Controller reagiert nicht | eine Taste am Controller drücken, neu einstecken, anderer USB-Port |
| Touch-Tasten fehlen | einmal auf den Bildschirm tippen. Tasten sind nur während der Runde sichtbar |
| „Bitte Gerät quer halten“ | Tablet drehen, Bildschirmdrehung nicht sperren |
| Tablet zeigt alte Version | App schliessen, mit Internet neu öffnen (lädt im Hintergrund), nochmals neu starten |
| Tablet startet ohne Anmeldung | Adresse ohne `?messe` geöffnet → mit `?messe` neu zum Home-Bildschirm hinzufügen |
| Export lädt nichts herunter | im Admin „Inhalt kopieren“ und in eine Datei oder Mail einfügen |
| Spiel ruckelt | andere Programme schliessen, Netzteil anschliessen |

Nichts davon passt? Neues Issue mit der Vorlage **„🐞 Fehler melden“**.
