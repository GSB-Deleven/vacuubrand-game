# 🤝 Mitarbeit und Planung

| Werkzeug | Wofür |
|---|---|
| 💬 **Discussions** | lose Ideen, Fragen, Messe-Feedback |
| ✅ **Issues** | konkrete Aufgaben, Fehler, Textänderungen (mit Vorlagen) |
| 🧩 **Epics** | Sammel-Issues mit Unteraufgaben und Fortschrittsbalken: „Messe-bereit“, „GitHub einrichten“, „Ideen-Backlog“ |
| 🏁 **Milestones** | Termine: „v1.1 Tablet & Online“, „Messe 2026 bereit“, „Nach der Messe“ |
| 🗂️ **Project-Board** | Überblick: Backlog → To do → In Arbeit → Warten auf Freigabe → Erledigt |
| 🔀 **Pull Requests** | jede Änderung wird als PR vorgeschlagen und nach Prüfung gemergt, danach ist sie automatisch online |

## Von der Idee zur Umsetzung

1. Idee in **Discussions → Ideen** posten und besprechen
2. Wenn klar ist, was gemacht werden soll: **„Create issue from discussion“**
3. Im Issue **@claude** schreiben (oder Label **claude** setzen)
4. Claude antwortet im Issue, setzt die Änderung um und bereitet einen **Pull Request** vor
5. Pull Request anschauen, ggf. in der Online-Demo prüfen, **mergen**
6. Das Issue schliesst sich automatisch, die Änderung ist 1 bis 2 Minuten später online

Fachliche Fragen (Produktaussagen, Texte, Datenschutz) klärt Claude im Issue, statt zu raten.

## Einmalige Einrichtung

Siehe Epic **„🐙 GitHub einrichten“** in den Issues: Pages, Milestones, Project, Discussions, Claude-Token.
