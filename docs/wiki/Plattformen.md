# 🌍 Plattformen

Das Spiel ist eine Webseite ohne Installation. Es läuft überall, wo ein aktueller Browser läuft.

| System | Start-Datei (Doppelklick) |
|---|---|
| 🪟 Windows | `▶ START Windows.bat` (Edge im Vollbild) |
| 🍎 Mac | `▶ START Mac.command` (Chrome/Edge im Vollbild, sonst Safari). Beim ersten Mal: Rechtsklick → **Öffnen** → Öffnen |
| 🐧 Linux / 🍓 Raspberry Pi | `▶ START Linux + Raspberry Pi.sh` (Chromium im Vollbild). Automatisch beim Einschalten: siehe `raspberry-pi/README.md` |
| alle | Notfalls einfach `index.html` doppelklicken |

## 📱 iPad und iPhone

1. Online-Link öffnen: https://gsb-deleven.github.io/vacuubrand-game/ (am Stand mit `?messe` am Ende)
2. **Teilen** → **„Zum Home-Bildschirm“**
3. Ab jetzt über das App-Symbol starten: Vollbild, quer, läuft auch ohne Internet

Safari kennt auf dem iPhone keinen Vollbildmodus, deshalb der Umweg über den Home-Bildschirm. Ton startet nach der ersten Berührung.

## 🤖 Android

Online-Link in Chrome öffnen, Menü ⋮ → **„App installieren“**.

## 🍓 Raspberry Pi / Arcade-Automat

Raspberry Pi 4 oder 5 mit Raspberry Pi OS. Nach dem einmaligen Einrichten startet der Pi direkt ins Spiel. Anleitung: [raspberry-pi/README.md](https://github.com/GSB-Deleven/vacuubrand-game/blob/main/raspberry-pi/README.md)

## 🕹️ Joystick, Gamepad, Arcade-Knöpfe

- Gamepads (Xbox-Layout) und USB-Joysticks werden automatisch erkannt.
- Arcade-Encoder mit Steuerkreuz als „Hat“ werden ebenfalls erkannt.
- Liegen Knöpfe falsch: Admin-Bereich → **Controller / Joystick → Controller einrichten** und die Knöpfe der Reihe nach drücken.
- Arcade-Tastatur-Encoder (z. B. I-PAC): Pfeiltasten, Leertaste, Ctrl/Shift, Enter. **1** und **5** starten.

## Wichtig

Bestenliste und Leads werden im jeweiligen Browser gespeichert. Also immer mit derselben Start-Datei bzw. derselben App starten.
