# 📱 Tablet und Online

Es gibt nur **eine** Version des Spiels. Welche Variante startet, hängt von der Adresse ab:

| Adresse | Variante |
|---|---|
| Doppelklick auf `index.html` | Messe (Laptop) |
| [https://gsb-deleven.github.io/vacuubrand-game/?messe](https://gsb-deleven.github.io/vacuubrand-game/?messe) | Messe auf dem Tablet: Anmeldung, Admin, Export |
| [https://gsb-deleven.github.io/vacuubrand-game/](https://gsb-deleven.github.io/vacuubrand-game/) | Online-Demo: nur Spitzname, keine Kontaktdaten, kein Admin |

## Tablet am Stand einrichten

1. Adresse mit **`?messe`** öffnen
2. Als App installieren: iPad: Teilen-Symbol → **„Zum Home-Bildschirm“**. Android: Menü ⋮ → **„App installieren“**
3. Ab jetzt über das App-Symbol starten: Vollbild, quer, läuft auch **ohne WLAN**
4. Beim ersten Antippen erscheinen die Bildschirm-Tasten
5. **Admin:** 3 Sekunden auf das VACUUBRAND-Logo oben drücken, dann PIN

Die Daten liegen nur auf diesem Tablet. Export über den Admin-Bereich (notfalls „Inhalt kopieren“ und per Mail an sich selbst).

## Online-Demo

Für Website, Newsletter oder Social Media. Besucher geben nur einen Spitznamen ein. Punkte und Bestenliste bleiben auf ihrem eigenen Gerät, es werden keine Daten übertragen.

## Updates

Jede Änderung auf `main` ist nach 1 bis 2 Minuten online. Installierte Tablets holen die neue Version beim nächsten Start mit Internet.
