# 🛠️ Technik

Reines HTML, CSS und JavaScript mit Canvas, keine Frameworks, keine Installation. Grafik, Schrift und Sound entstehen im Code.

| Datei | Aufgabe |
|---|---|
| `index.html` | Startseite, lädt alles |
| `js/config.js` | **alle Einstellungen** (Zeit, Punkte, Pumpen, Texte der Anmeldung) |
| `js/level.js` | Levelaufbau: Blöcke, Gegner, Schilder |
| `js/game.js` | die Spielrunde |
| `js/entities.js` | Professor, Gegner, Items, Endgegner |
| `js/scenes.js` | Start, Ergebnis, Bestenliste |
| `js/ui.js` | Anmeldung, Admin |
| `js/input.js`, `js/touch.js` | Tastatur, Gamepad, Touch |
| `js/storage.js` | Speichern, Bestenliste, Export |
| `js/sprites.js`, `js/font.js`, `js/sound.js` | Pixelgrafik, Schrift, Musik |
| `sw.js`, `manifest.webmanifest` | App-Installation und Offline-Betrieb |
| `.github/workflows/` | Online-Veröffentlichung und Claude-Automatik |

Das ausführliche Handbuch mit Spielmechanik, Datenformat und Kochrezepten zum Anpassen: **[TECHNIK.md](https://github.com/GSB-Deleven/vacuubrand-game/blob/main/TECHNIK.md)**

Regeln für Änderungen (auch für Claude): [CLAUDE.md](https://github.com/GSB-Deleven/vacuubrand-game/blob/main/CLAUDE.md)
